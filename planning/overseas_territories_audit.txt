GEOCONQUEST - OVERSEAS TERRITORIES / FAR-FLUNG PARTS AUDIT
=========================================================
Source: app/assets/map/countries-50m.json (the outlines the app uses)
Method: script splits each country into its separate land parts, starts
from the biggest part, and keeps every part within N degrees of a kept
part (so island chains stay connected). Anything left over is "far".
Run with N = 8 deg (loose) and N = 3 deg (strict).

WHY IT MATTERS
  Shape Quiz, Daily Zoom, Neighbours tiles, Compass Quiz (country centre
  and "from" view), Learn More zoom: all fit the view to the WHOLE
  outline, so far parts shrink the country to dots or shift its centre.

PROPOSED APPROACH
------------------------------------------------------------------------
  1. One-time script builds a "display outline" per country:
     automatic rule (~8 deg) + a small manual override table for the
     section B countries (keep/drop specific parts).
  2. Save the result as a data file shipped with the app; all shape
     views (Shape Quiz, Zoom, Neighbours, Compass, Learn More) use it.
     The full outline is still used where the whole territory matters
     (world map / conquest map, km2).
  3. Fix date-line countries (Russia, USA, Fiji, NZ, Kiribati) so they
     draw as one piece instead of being split across the map edge.
  4. One visual review: render every country's display outline into a
     contact sheet image and check it by eye.

E. MISSING SHAPES (the "?" problem)
========================================================================
WHY A "?" APPEARS
  The shape view looks the country up in the world map file by its
  number. If it's not there, it shows "?". Causes:
   1. The country isn't in the map file at all (list below).
   2. The country has no number in the map file: Kosovo (also
      Somaliland, N. Cyprus - not app countries).
   3. The shape view downloads the whole world map from the internet
      (cdn.jsdelivr.net) every time; a slow or failed download leaves
      the view stuck. The same file is ALREADY bundled in the app
      (app/assets/map/countries-50m.json) - use that instead.
  Note: Australia and "Ashmore and Cartier Is." share the same number
  in the file; the app happens to pick Australia because it's first.
  The new shape file should not depend on that.
