FEATURE 1: DAILY QUESTS
------------------------------------------------------------

DECISIONS SO FAR
  - REMOVE the Daily Leaderboard entirely (Daily tab, the #1 daily
    prize, and its server logic). Leaderboard keeps: Weekly + All-time.
  - REMOVE the "reward just for logging in". Nothing is granted for
    opening the app anymore.
  - ADD 3 daily quests per player, Duolingo style:
      * "Daily Quests" section with a countdown to reset
      * One row per quest: title, progress bar (e.g. 20 / 20), chest icon
  - Each quest has a reward chest. The HARDEST quest's chest is the
    "Daily Chest" (the reward that used to come from logging in).
  - Quests may overlap in objective (e.g. "Earn XP" and "Complete 3
    quizzes" fill together), like Duolingo.
  - Every quest is a TEMPLATE with a number that can change, so one
    template gives an Easy, Medium and Hard version. New quest types =
    one new template, not new code per quest.
  - Note: the newest app version (with the daily chest logic) is not in
    this repo, so this is a pure design and will be reconciled with that
    code when implementation starts.

1C. RULES FOR PICKING EACH DAY'S 3 QUESTS
  - One Easy, one Medium and one Hard every day.
  - Overlap allowed, but no two quests from the same template on the
    same day.
  - Never give a quest the player can't do: no Nightmare without the
    Dark Scroll, no Millionaire with 0 tickets, no locked modes.
  - Time limit: the Hard quest should take about 15-20 minutes of play
    at most.
  - Bias toward neglected modes: favour modes the player hasn't played
    lately (helps discovery).
  - Ease in new players: for their first 3 days, only easy-ish versions.
  - Weights and amounts live in the database: every template, its
    numbers per tier, how often it's picked, and its reward are stored
    in a table, editable / switchable from the admin dashboard.

  - Conqueror subscribers: 3x on the Daily Chest (moved from the old

FEATURE 2: WEEKLY CHALLENGE  (next to design)
------------------------------------------------------------
Requirement: must be PERCENTAGE / result based, not totals, because
"most XP" or "most gold" gives high-level players a huge edge.

Starting ideas:
  - Best % in this week's fixed quiz (same question set for everyone,
    fastest time as tiebreaker)
  - Highest average accuracy across the week (minimum number of quizzes)
  - Biggest improvement over your own previous week
  - Level brackets / leagues so new players don't compete with veterans

Earlier suggested defaults to revisit:
  - Week: Monday 00:00 UTC to Sunday 23:59 UTC
  - Attempts: 1 free, extra attempts cost a ticket, best score counts
  - Challenge picked by an automatic rotation of templates, with a
    dashboard override
  - Prizes for 1st-3rd (+ maybe participation reward, exclusive
    avatar/frame for 1st), amounts set in the dashboard
  - New "Weekly" tab on the Leaderboard

FEATURE 4: PASSPORT  (to design)
------------------------------------------------------------
Suggested so far:
  - Passport replaces Home + Quests -> tabs: Passport, Quizzes, Shop,
    Leaderboard
  - Subtabs: Stamps | Quests | Conquests (owned countries) | Collection
    (owned avatars + upgrades, with equipping)
  - Home content moves: stats -> Passport header, profile menu ->
    behind avatar in header, Top Explorers -> Leaderboard
  - Stamp chance: 0.1% per correct answer is ~1 stamp per 100 quizzes,
    so suggested a ~3% base (dashboard-adjustable) + guaranteed stamp
    after N dry quizzes + rarity tiers by country difficulty
  - Stamp = the country the question was about; only rolls countries
    the player doesn't have yet
  - Small "Stamp found!" chip mid-quiz, full animation on results
  - Animation: passport opens, stamp slams down (squash), ink spreads,
    small screen shake, heavy haptic, "THUNK" + paper sound, rarity glow
  - Stamp art generated automatically (vector), not hand-drawn
  - Stamp milestone quests (10/50/100, full continent) + share image

FEATURE 5: ECONOMY CONFIG IN THE DASHBOARD  (to design)
------------------------------------------------------------
Findings from the current code:
  - Prices/rewards are hard-coded in many places (ticket cost 2000 and
    8500 pack in both Shop and Quiz Menu screens, avatar list, daily
    reward cycle, leaderboard prize in app + database, referral 1500,
    database purchase functions).
  - Quiz gold is calculated on the phone, then saved.
  - Dashboard is a single HTML page (GitHub Pages) using the admin
    database key; it already has a read-only Economy tab.
Suggested so far:
  - New game_config table (key, value, description, updated_at);
    players read it, only the admin key writes it; app loads it at
    launch with built-in fallback defaults
  - Editable: quiz gold/XP per mode, ticket/pack prices, chest rewards,
    weekly prizes, referral bonus, country/avatar/upgrade prices, crate
    odds, stamp chance, quest templates & rewards
  - Move gold reward calculation to the server (anti-cheat)
  - Changes apply on next app open / return to foreground
  - Change history + validation in the dashboard

FEATURE 6: COMPASS MODE  (to design)
------------------------------------------------------------
Suggested so far:
  - Random "from" country centred on the map, target named; pairs
    reasonably far apart, tiny islands excluded
  - "Correct direction" = the straight line as drawn on the app's flat
    (Mercator) map, so the answer matches what players see
  - Scoring: within 10 deg full, within 30 deg partial, else wrong
  - Drag the arrow around a compass dial (1 deg steps, N/E/S/W), Confirm
  - After answering: map zooms out to show both countries, draws the
    correct line next to the player's arrow, shows the error in degrees
  - 10 rounds, 15s timer, free like Flags
  - Counts toward quests and stamps (stamp = target country)
  - Name ideas: Compass / True North / Bearing
